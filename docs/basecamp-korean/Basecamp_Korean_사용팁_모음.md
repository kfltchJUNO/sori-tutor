# Basecamp Korean — 사용 팁 모음 (추후 일괄 반영용)

나중에 워크북이나 본교재 'Tip 박스'로 일괄 반영할 자연스러운 구어 표현/생략 규칙을 여기에 계속 모아둡니다.

## 5과 관련 (에/위치 표현)

1. **여기/거기/저기 + 있어요일 때 '에' 생략 가능**: "저기에 있어요" → 구어에서는 "저기 있어요"처럼 '에'를 생략하는 경우가 많음. 지시대명사 자체가 이미 장소성을 내포하기 때문.
2. **'안' 생략 조건 (아늑한/경계가 뚜렷한 공간)**: "교실 안에 있어요" → 일반적으로 "교실에 있어요"로 줄여 써도 자연스러움. 경계가 뚜렷한 실내 공간(교실, 가방, 상자 등)은 '안'을 생략해도 '내부'라는 의미가 유지됨.
3. **큰 규모 장소는 '안' 사용이 어색함**: "학교 안에 있어요", "한국 안에 있어요"처럼 규모가 큰 장소·국가 단위에 '안'을 붙이면 어색함. 이런 경우는 그냥 "학교에 있어요", "한국에 있어요"가 자연스러움. ('안'은 물리적으로 경계가 뚜렷하고 상대적으로 작은 공간에 어울림)

## 1과 관련 (자기소개)
4. **주어 생략**: "이름이 뭐예요?"에 답할 때 자연스러운 구어에서는 "저는"을 생략하고 바로 "OO예요"라고만 답하는 경우가 많음 (문맥상 주어가 명확하기 때문).
5. **저희 vs 우리**: "저희 가족"은 낯선 사람에게 격식 있게 말할 때, "우리 가족"은 친한 사이에서 더 자연스러움. 지금은 저희로 통일했지만 추후 우리와 병기 고려.

## 2과 관련 (사물/가격)
6. **조사 생략**: 캐주얼한 구어에서는 "이거 뭐예요?"에서 이/가를 아예 생략하는 경우가 흔함 (이게 뭐예요 > 이거 뭐예요, 둘 다 자연스러움).

## 3과 관련 (동사 현재형)
7. **을/를 생략**: 구어에서는 "커피를 마셔요" 대신 "커피 마셔요"처럼 을/를을 생략하는 경우가 매우 흔함. 격식 있는 글쓰기에서는 유지 권장.
8. **여기/거기/저기 + 가다도 '에' 생략 가능**: 5과 팁 2번과 마찬가지로 "저기에 가요" → "저기 가요"도 자연스러움 (있다뿐 아니라 가다/오다에도 적용).

## 4과 관련 (안/못)
9. **-지 않다 (formal alternative)**: 안 대신 'V-지 않아요'라는 더 격식 있는/문어체 부정 표현도 있음 (예: 가지 않아요 = 안 가요). Book2 후반부나 워크북 심화에서 소개 고려.

## 7과 관련 (요청/희망/미래)
10. **-고 싶어요는 1인칭 전용**: -고 싶어요는 화자 자신의 희망에만 씀. 3인칭(그 사람, 유키 씨 등)의 희망을 말할 때는 '-고 싶어 해요'로 바뀜 (예: 유키 씨는 여행하고 싶어 해요). 학습자가 자주 틀리는 포인트라 Book2에서 명시적으로 다룰 가치 있음.
11. **잠시만요의 확장 사용**: "잠시만요"는 카페 주문 상황뿐 아니라 전화 받을 때, 길을 비켜달라고 할 때 등 '잠깐만요'가 필요한 모든 상황에서 두루 쓰임.
12. **-(으)ㄹ 거예요의 추측 용법**: 지금은 '계획'으로만 가르쳤지만, 같은 형태가 '추측'(예: 비가 올 거예요 = 비가 올 것 같아요)에도 쓰임. Book2 이후 심화 확장 후보.
